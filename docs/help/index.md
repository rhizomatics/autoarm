# Help and Support

If you can't find an answer here, try the [GitHub Discussions](https://github.com/rhizomatics/autoarm/discussions) where you can find advice other people requested, or raise your own request.

If you think its a bug, raise a bug request, or see if anyone else has the same problem at the [GitHub Issues](https://github.com/rhizomatics/autoarm/issues) page.
